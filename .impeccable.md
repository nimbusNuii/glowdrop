## Design Context

### Users
- The owner plus their friends: Mac users (Apple Silicon and Intel), mixed technical skill, Thai and English speakers.
- They want a free replacement for paid live-wallpaper apps (Backdrop): pick a moving wallpaper in a couple of clicks, add their own video files, and forget the app is running.
- Context of use: quick visits. Open the gallery, choose or add a video, close it. The app otherwise lives in the menu bar and must stay light on CPU, GPU and battery.
- Distribution: a public GitHub repository and release build that friends install themselves. The app is offline-only — it never connects to the internet; users bring their own videos (library folder, drag-and-drop, Open With).

### Brand Personality
- Three words: light, familiar, neon-playful (derived from the conversation; adjust if it stops fitting).
- Voice: short, friendly, plain Thai/English labels; no jargon ("Low Power Mode" yes, "occlusion" no).
- Emotional goal: calm confidence — "it just works and it's mine" — with a small spark of fun from neon accents and the wallpapers themselves.

### Aesthetic Direction
- macOS-native first: standard SwiftUI/AppKit controls, a real Settings window (⌘,), menu-bar extra, `NavigationSplitView` sidebar + content like System Settings / Apple's own apps.
- Neon is an accent, not a theme: `Theme.neon` marks state only (current wallpaper stroke + glow, Playing badge, drop target, toggles), never large surfaces or body text. The wallpaper thumbnails are the color in the UI.
- Gallery window is always dark (thumbnails pop); the Settings window follows the system appearance. Sidebar selection keeps the native system highlight.
- References: Backdrop (gallery of large thumbnails, one-click apply), macOS System Settings (sidebar + grouped forms), Plash (menu-bar simplicity).
- Anti-references: game-launcher UI with glow everywhere, store/ad-like layouts, cluttered toolbars, anything that needs an account or a download to look complete.
- Localization: Thai and English, following the macOS language with an override in Settings; every string through `L10n`.

### Design Principles
1. **The wallpaper is the hero.** Chrome stays quiet and native; thumbnails carry the color. Neon marks state only.
2. **Native before custom.** Prefer system controls, layouts and shortcuts friends already know; custom styling only where it adds meaning.
3. **Light by default.** Offline, no network code paths, auto-pause when nobody sees the wallpaper; make energy choices visible and honest in Settings.
4. **Friend-proof.** Every action discoverable without explanation: drag-and-drop or "Add Video…", clear empty states, inline banners instead of modal alerts, both languages.
5. **Public-safe.** Ship no copyrighted media or trademarks in the repo or release; users bring their own content.
